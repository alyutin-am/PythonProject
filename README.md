# Проект "New widget"

## Описание
Проект "New widget" - это виджет, который показывает несколько последних успешных банковских операций клиента. 
Статус: в разработке

## Установка:

1. Клонируйте репозиторий:
```
get clone https://github.com/alyutin-am/PythonProject.git
```

2. Установите зависимости:
```
poetry install --no-root 
```

## Использование:
Виджет еще не доработан и не предполагает использование на данный момент. Имеется только отдельный набор функций:
1. **filter_by_currency** -  Функция принимает на вход список словарей и возвращает итератор,
    который поочередно выдает транзакции, где валюта операции соответствует currency
2. **transaction_descriptions** - Генератор принимает список словарей с транзакциями и возвращает описание каждой операции 
    по очереди
3. **card_number_generator** - Генератор выдает номера банковских карт в формате XXXX XXXX XXXX XXXX, где X — цифра номера 
    карты.Генератор может сгенерировать номера карт в заданном диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999.
4. **get_mask_card_number** - Функция скрытия номера карты (замены части номера карты на '*')
5. **get_mask_account** - Функция скрытия номера счета (замены части номера счета на '*')
6. **filter_by_state** - Функция возвращает новый список словарей, содержащий только те словари,
    у которых ключ соответствует указанному значению, по умолчанию 'EXECUTED
7. **sort_by_date** - Функция должна возвращать новый список, отсортированный по дате,
    имеет возможность сортировки по возрастанию или убыванию
8. **mask_account_card** - Функция маскировки номера карты/счета с выводом карты/счета
9. **get_date** - Функция вывода даты
10. **@log** - Декоратор автоматически регистрирует детали выполнения функций: время вызова, имя функции, 
передаваемые аргументы, результат выполнения и информация об ошибках
